# Meena Bazar Web Scraper 🛒

A **Python-based automation tool** to scrape product data from [Meena Bazar](https://meenabazaronline.com/)’s website. This project extracts structured product information and organizes it into CSV files for easy analysis.  

> **Note:** This project is for **educational purposes only**. No copyright infringement is intended.  

---

## Features ✨

- **Product URL Collection:** Crawl main category pages and extract all product URLs.  
- **Data Scraping:** Fetch product details including product name, category, sub-category, brand, price etc.  
- **CSV Output:** Export cleanly structured CSV files for all scraped data.  
- **CLI Interaction:** Run scripts from the terminal with real-time progress feedback.
